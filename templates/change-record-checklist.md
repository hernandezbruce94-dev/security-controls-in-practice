# Change record checklist (book Chapters 3 and 20)

- [ ] Intent and affected control register entries
- [ ] Mapped framework requirements (from `mapping/framework-mapping.csv`)
- [ ] Exact objects and values to change
- [ ] For shared policies: every application or scope that uses the object (Case 4-A)
- [ ] Pre-change baseline export or snapshot reference
- [ ] Pilot scope (dedicated group) and observation period
- [ ] Verification cases with expected observations, written before execution
- [ ] Rollback steps as commands or console steps, exercised in staging
- [ ] Propagation or activation delays accounted for (Chapters 10, 16)
- [ ] For Panorama: commit **and** push job IDs (Case 7-E)
- [ ] Monitoring or alert to confirm the change did not drift
- [ ] Post-change baseline export committed
- [ ] Approvals (owner, change board; data owner if scope changes)
